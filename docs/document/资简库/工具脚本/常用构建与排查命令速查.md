# 常用构建与排查命令速查

收录本站日常构建、数据生成与排查中最高频的命令，按使用场景分组。

<!-- more -->

## 本站

```bash
pnpm dev      # 开发预览（自动生成热力图数据）
pnpm build    # 构建产物到 docs/.vitepress/dist
pnpm preview  # 本地预览构建产物
```

## GitHub Pages 构建模拟

```bash
BASE_PATH=/Scriptorium/ pnpm build
```

## git

```bash
git log --oneline -10                 # 近 10 条提交
git log --name-only --since="1 week"  # 一周内变更的文件
git log --name-only --pretty=format:@%ad --date=short -- docs/   # 热力图数据源命令
```

## Node / pnpm

```bash
pnpm why <pkg>        # 查依赖为何被引入
pnpm store prune      # 清理包存储
corepack enable       # 启用 pnpm
```
