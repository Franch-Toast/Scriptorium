**一句话**：检测模型对同一个目标会吐出一堆高度重叠的候选框，NMS（Non-Maximum Suppression）按「分数优先、重叠淘汰」只留下最好的那几个——检测后处理的标配工序。

**是什么**：模型的输出方式决定了重复：滑动窗口、多种锚框、多尺度特征都会「同时命中」同一物体——一辆车身后跟着十几个叠着的框。NMS 的流程：把候选框按分数从高到低排队 → 取最高分的框保留 → 删掉与它重叠度（用 IoU 衡量）超过阈值的所有框 → 再取剩下里面分数最高的 → 重复直到队空。留下的都是「分数的局部极大值」，所以叫「非极大值抑制」——抑制的就是那些重叠的非极大者。

**生活类比**：十份目击证词都在描述同一把椅子，位置略有出入。按「最详细的那份优先」收录一份，与它高度雷同的证词一律撤掉；再处理下一件物品——直到每件物品只剩一份证词。

**在 C01 项目中的体现**：mono3d 检测任务的后处理对模型输出做去重得到最终目标框；camera 双视场（traffic_2 与 traffic_2_crop）合并前还有一轮「软化 IoU」去重，思路与 NMS 同源（见 [camera 子模块 1](../../../撰修司/E2E架构拆解/Perception/02_核心子模块拆解/子模块1：camera%20相机感知子模块.md)）。
