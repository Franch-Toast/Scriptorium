**一句话**：采样是把连续的世界（或曲线）按固定间隔取点变成离散序列；插值是反过来用已知离散点推算任意中间点——一对方向相反的操作。

**是什么**：**采样**（sampling）：连续信号/空间每隔一定间隔取一个值——点云按距离切片、路径规划在候选空间里撒点、ST 图按时间/里程切网格。采样密度决定分辨率与计算量：太稀会漏掉细节，太密算不动。**插值**（interpolation）：在已知离散点之间按某种光滑规则（线性、样条等）推算中间位置的值，让离散数据能以「连续」的姿态被查询。

**生活类比**：采样 = 每年生日拍一张照（连续的人生被离散成年度照片）；插值 = 想知道 25 岁半的样子，就拿 25 岁和 26 岁两张照片按比例「脑补」一张。拍得太稀（十年一张）就认不出渐变过程，拍得太密又存不下。

**在 C01 项目中的体现**：dp_path 的 sampler 生成路径候选点，是 DP 搜索的原材料（见 [Planning 子模块 1](../../../撰修司/E2E架构拆解/Planning/02_核心子模块拆解/子模块1：planner%20与%20tasks%20决策规划任务管线.md)）；trajectory_checker 发现碰撞点后，按 s 位置插值出该处的制动加速度随轨迹下发（见 [Planning 子模块 4](../../../撰修司/E2E架构拆解/Planning/02_核心子模块拆解/子模块4：trajectory_checker%20轨迹校验子模块.md)）；预测模块按浮点时刻插值访问历史轨迹点（见 [Planning 子模块 6](../../../撰修司/E2E架构拆解/Planning/02_核心子模块拆解/子模块6：continuous_object_prediction%20目标预测子模块.md)）。
