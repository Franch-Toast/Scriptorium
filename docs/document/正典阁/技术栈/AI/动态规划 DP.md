**一句话**：把一个复杂决策拆成多阶段小决策、每个阶段只记「到此为止的最优」，从而快速得到全局粗解——规划器里负责「先粗后细」的前半段。

**是什么**：DP = Dynamic Programming（动态规划）。当一个问题的「大局最优」可以由「各阶段在剩余情形下的最优」组合而成时，就能逐阶段把最优子解存表复用，避免穷举所有可能路径。它天生是离散化的：只在有限的「格子/候选点」里挑最优，所以解是折线——方向全局正确但不够平滑，这正是它需要后续优化的原因。

**生活类比**：走迷宫的「逐格记账法」——不把每条路都走一遍，而是每到一格就在账本记下「到这里最少几步」；后面的格子只查前面格子的账本取最小值。账本让重复计算归零，这就是 DP 比穷举快的全部秘密。

**在 C01 项目中的体现**：EmPlanner 用 DP 做「粗解」：dp_path 在采样出的路径候选里用 DP 选出初始路径（含 path_cost/path_graph/sampler 等子模块），dp_speed 在 ST 图里选出粗速度曲线；随后交给 QP 精化。DP 结果不平滑但全局稳妥——它既是 QP 的初值，也是 QP 失败时的兜底结果（见 Planning 子模块 1（E2E 主干 07《规划模型》））。
