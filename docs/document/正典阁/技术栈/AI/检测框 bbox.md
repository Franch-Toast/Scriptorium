**一句话**：用一个矩形（图像上）或长方体（3D 空间）框住目标的最小外接框——目标检测任务的输出基本单元。

**是什么**：bbox = bounding box（边界框）。2D 检测输出 (x, y, 宽, 高) 加类别与分数；自动驾驶更关心 **3D 框**：中心点 (x, y, z)、长宽高、朝向角（yaw）——完整表达「一辆车在自车坐标系里在哪、多大、车头朝哪」。检测模型的原始输出是「一大堆候选框 + 类别 + 分数」，经过去重（NMS）、阈值过滤后，才留下一个个确定的目标框，交给跟踪器串成轨迹。

**生活类比**：仓库管理给每件不规则货物套上一个最小号的「标准周转箱」再贴标签入库——箱子（框）不等于货物本身，但给了它一个可计算的位置、尺寸与朝向，后续调度全靠这个箱子说话。

**在 C01 项目中的体现**：uni_model 的 mono_results 张量经 mono3d 任务头后处理解码成 detection3d_objects（3D 目标框列表），是相机感知的核心产出之一（见 camera 子模块 1（E2E 主干 05《感知大模型》））；轨迹校验时自车也有包围盒（含/去后视镜两种 box 口径）用于碰撞判定（见 Planning 子模块 4（E2E 主干 07《规划模型》））。
