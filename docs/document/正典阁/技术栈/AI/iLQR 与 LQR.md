**一句话**：LQR 是「线性系统 + 二次代价」下能用公式直接解出最优控制序列的经典方法；iLQR（iterative LQR）把它迭代化，用来给真实（非线性）车辆动力学下的轨迹做局部最优精修。

**是什么**：LQR = Linear Quadratic Regulator。当系统动力学是线性的（下一状态 ≈ A×当前状态 + B×控制量）、代价是二次的（偏离目标的误差 + 控制量的大小，都取平方），数学上可以推出解析最优解——不用搜索、不用迭代，一套公式出结果。但真实车辆是非线性的（轮胎侧偏、空气阻力），于是 iLQR 的思路是：先拿一条初始轨迹，在轨迹附近把非线性系统线性化成「一小段一小段的 LQR」，解出局部修正量；更新轨迹后再线性化、再修正……如此迭代，直到收敛到局部最优轨迹。

**生活类比**：窄位泊车打方向——在「一小段近似直线」里可以按公式一步算出该打多少（LQR）；真实泊车是打一点、看车实际走到哪、再修正、再打，几轮下来逼近一条顺滑入位轨迹（iLQR）。
