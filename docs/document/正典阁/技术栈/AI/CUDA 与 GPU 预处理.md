**一句话**：GPU 用上千个小核心并行处理海量同构计算；CUDA 是给 GPU 写并行程序的平台——车端把图像解码/缩放/裁剪/归一化等预处理搬上 GPU 并行执行，又快又省得把结果直接喂给神经网络。

**是什么**：CPU 有几十个强核心，擅长复杂逻辑与分支；GPU 有上千个小核心，擅长「对一大堆数据做同一件事」——图像逐像素处理、矩阵乘法、卷积都是这类活。CUDA（Compute Unified Device Architecture）是 NVIDIA 的 GPU 并行计算平台：写一个 kernel（在 GPU 上被成千上万个线程同时执行的函数），把它撒到所有像素上并行完成。深度学习的核心运算天然适合 GPU，而推理前后的数据准备（预处理）若留在 CPU 做，既慢又要来回搬运数据——搬上 GPU 一步到位。

**生活类比**：CPU 是几位老师傅（什么都能干但人少）；GPU 是一整个营的士兵（每人只会简单动作但人数庞大）。给一万张照片统一盖章（逐像素预处理），派士兵排队流水线远快于老师傅逐张盖章。

**在 C01 项目中的体现**：camera 子模块把「图像 GPU 预处理：解码/缩放/裁剪/归一化」作为 uni_model 的 imgs 输入前的固定工序（见 [camera 子模块 1](../../../撰修司/E2E架构拆解/Perception/02_核心子模块拆解/子模块1：camera%20相机感知子模块.md)）；uni_model 单模型方案（一次前向摊薄 GPU 开销、各任务共享 BEV 特征）本身也是围绕 GPU 成本的设计决策。
