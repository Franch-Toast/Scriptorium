**一句话**：用分段光滑的多项式曲线（样条）穿过或逼近离散数据点——把「折线」变成车辆可执行的光滑轨迹。

**是什么**：样条（spline）= 分段多项式拼接而成、拼接处导数连续的光滑曲线——数学版的「曲线板」。曲线拟合 = 在一族曲线里找一条最贴近给定点的。工程意义：DP 搜出来的是离散候选点连成的折线，直接执行意味着方向盘「一格一格」地抖；对折线做样条拟合，既保持形状（该躲哪躲哪）又获得连续的曲率与加加速度——这是「先粗后细」中「细」的数学载体。样条的阶数与节点决定了光滑程度上限。

**生活类比**：连点成画有两种连法——直尺逐段连（折线，处处急拐）与曲线板逐段描（样条，处处顺滑）。给定同样的关键点，曲线板描出的那条才是能上赛道跑的线。

**在 C01 项目中的体现**：路径侧 QpSplinePathOptimizer 把 DP 折线拟合成样条（QP_path，tasks/qp_spline_path/），是 EmPlanner「DP 粗解 → QP 精修」接力链的精修半程（见 Planning 子模块 1（E2E 主干 07《规划模型》））。
