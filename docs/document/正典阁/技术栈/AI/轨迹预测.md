**一句话**：根据目标的当前状态与历史轨迹，推算它未来几秒可能走的位置序列——这是规划器决策前的「对手棋谱」。

**是什么**：预测分两档。**物理外推**：用运动学公式（匀速、恒定转弯率）把当前状态往前推——简单可靠，但猜不到变道急刹。**学习式预测**：把历史轨迹、地图约束、周边交互一起喂给神经网络，输出多条候选未来轨迹（多模态）及各自概率——「多模态」意思是前方路口既可能直行也可能左转，模型各给一条候选而不是硬选一个。预测质量直接决定规划是「从容让行」还是「误刹/漏让」。

**生活类比**：下棋猜对手——新手只看他当前落子（当前状态）；高手看他前几步的习惯（历史轨迹）加棋盘局势（地图约束）来猜下一手，并且准备好两三种应对（多模态候选）。

**在 C01 项目中的体现**：预测出现在两处。感知侧：PredictionWithPlannerCalculator 产出他车预测，并有 /planner/trajectory 回灌的规划轨迹先验（自车意图）作为 optional 通道参与预测（见 Perception 05 输出发布（E2E 主干 06《后处理》）、farseer 子模块 4（E2E 主干 05《感知大模型》））；规划侧：continuous_object_prediction 子模块维护他车意图与轨迹（见 Planning 子模块 6（E2E 主干 07《规划模型》））。
