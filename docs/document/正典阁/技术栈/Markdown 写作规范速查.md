# Markdown 写作规范速查

本篇汇总本站的 Markdown 写作约定，新文档按此模板起步。

<!-- more -->

## frontmatter 约定

```yaml
---
title: 文档标题        # 站点与搜索展示的标题
date: 2026-08-25      # 归档时间线使用
categories:           # 分类页聚合维度
  - 正典阁
tags:                 # 标签页聚合维度
  - 规范
---
```

## 行文约定

- 一篇文档只回答一个问题，长主题拆成系列并在文末互链；
- 标题层级从 `#`（文档标题）开始逐级递减，不要跳级；
- 命令、配置、报错信息一律用行内代码或代码块，不要用引号；
- 示例代码必须可复制执行，隐含前提写在代码块上方。

## 图表

- 架构与流程优先用 Mermaid，能被站点直接渲染；
