# 阶段一：需求梳理

## 现象采集

（示例内容）后台监控显示进程 CPU 在运行 6 小时后从 8% 缓慢爬升至 35%，重启后恢复，24 小时内可稳定复现。

<!-- more -->

## 排查方向确认

1. 定时器泄漏：确认是否存在周期任务未释放；
2. 数据结构无界增长：重点检查缓存类容器是否有淘汰策略；
3. 日志量放大：确认慢路径是否产生异常规模的日志 IO。
