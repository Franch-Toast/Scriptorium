# 欢迎来到 Scriptorium

这是一篇示例文档，帮助你快速了解本站的浏览与使用方式。

<!-- more -->

## 浏览方式

1. **目录树导览**：顶部导航「目录导览」可以按分区查看整棵文档树，与本地目录结构一一对应；
2. **时间线**：顶部导航「更新归档」按年月展示全站文档更新，页面顶部还有 GitHub 风格的更新热力图；
3. **全文搜索**：右上角搜索框支持站内全文检索，无需任何外部服务；
4. **侧边栏**：阅读任意文档时，左侧边栏展示所在分区的完整目录层级，新文档入库后自动出现。

## 写作约定

- 文档放在对应分区目录下，目录名即站点导航结构，**不要随意平铺到根目录**；
- 每篇文档建议携带 frontmatter（`title` / `date` / `categories` / `tags`）；
- 文件名用有语义的标题命名，站内 URL 由其自动生成。

## 内容会去哪里

本仓库是唯一内容源（Hub）。每次 `git push` 到 `main` 分支后，CI 会自动构建并发布到 GitHub Pages；公司内部站点与飞书云盘的接入方案见仓库 README 的「发布管线」章节。
