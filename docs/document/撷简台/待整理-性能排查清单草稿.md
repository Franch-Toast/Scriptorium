## CPU 类

- 先看火焰图整体形态：平顶（单个热点）还是多条高柱（均匀分散）；
- 平顶优先看调用深度，确认是业务逻辑还是运行时开销；
- 抓取窗口要覆盖复现时段，避免平均掩盖毛刺。

## 内存类

- 增长趋势看驻留曲线，单点峰值不一定有意义；
- 怀疑泄漏时用 heap profile 对比两个时间点，找只增不减的对象类型。
